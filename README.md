
# Python Banking System

A beginner-friendly banking management system built using Python.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- View account details
- Update account details
- Delete an account
- Store account records using JSON
- Streamlit web interface (if using the Streamlit version)

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- Git and GitHub
- Streamlit (for the web interface)

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Python-Banking-System.git
cd Python-Banking-System
```

### 2. Install dependencies

```bash
pip install streamlit
```

### 3. Run the Streamlit application

```bash
streamlit run app.py
```

If using the original terminal-based version, run:

```bash
python bank.py
```

## Note

This is an educational project. It is not intended
for real banking transactions or real customer data.
